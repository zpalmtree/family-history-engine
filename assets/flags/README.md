# Flag assets

`england.svg` and `wales.svg` are adapted from the 4×3 country-subdivision assets in [flag-icons](https://github.com/lipis/flag-icons). They retain the source artwork and add accessible labels plus square-fill behavior for the circular tree badges. See `LICENSE.flag-icons`.

The compact Germany, Ireland, Italy, and United States SVGs are project-local flag renderings.

`scotland.svg` (added 19 November 2026) follows the same flag-icons 4×3 subdivision artwork (`gb-sct`), with the accessible label and square-fill behavior of the England and Wales files.
