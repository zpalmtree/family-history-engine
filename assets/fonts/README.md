# Viewer fonts

Self-hosted because the viewer's Content Security Policy does not allow
third-party font hosts.

- Newsreader (names, headings and life stories): latin, latin-ext and latin
  italic subsets, variable weight 300–700.
- Public Sans (interface text and facts): latin and latin-ext subsets,
  variable weight 300–800.

Both are licensed under the SIL Open Font License 1.1; the licence texts are
`OFL-newsreader.txt` and `OFL-public-sans.txt`. Files were taken unmodified
from Google Fonts. If a file is replaced, give it a new name, because the
viewer serves fonts with a one-year immutable cache.
